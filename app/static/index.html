    Сдать клиенту
    1. Проверьте деталировку и комнату.
    2. Заполните цену и пароль (если нужен).
    3. Создайте HTML — файл скачается.
    4. Опубликуйте файл по инструкции ниже.

    Видео и публикация

    Видео пишется из окна 3D: включается облет, файл скачивается как .webm. Во время записи не трогайте модель.

    Публикация файлов — в панели «Сдать клиенту» (шаг 4, инструкция появятся после создания HTML).

    ИИ-чат

    Endpoint и модель — адрес и имя ИИ-сервиса, который вы подключили. Ключ хранится только на этом компьютере.
