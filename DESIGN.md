## Overview

Мир «Sample Catalog»: экран читается как папка образцов мебельного цеха.
Каждый материал — образец-чип с кодом (ДСП-08), каждый предмет и проект —
Каталожная запись с номером (01, ID demo). Тёмная тема — основная, светлая —
бумажный вариант той же папки. 3D-сцена — центр редактора. Режим Operate:
мир даёт только тип, палитру, плотность и подпись-ход «чип с кодом»;
компоновка и контролы — стандартные для рабочего инструмента.

Выбор сделан оператором: тёмный аккуратный (вариант А) из пяти скетчей;
страница выбора — `.impeccable/mocks/decision/*.html`, направление —
`.impeccable/surfaces/app-static-index-html.md`, seed:f5b9c68382c80086.

## Colors

- **Graphite** — тёмный фон, **panel/panel-2** — поверхности, **hairline** —
  тонкие линейки модулей. Светлая тема: **paper** фон, **ink** текст.
- **Amber** — единственный акцент (выбор, primary-кнопки, заголовки групп);
  в светлой теме темнее (**amber-deep**), чтобы держать контраст.
- **Oak / walnut** и остальные декор-цвета — палитра данных: они всегда
  показываются чипами с именами и кодами, а не «голыми» квадратами.
- Muted-текст ≥ 4.5:1 в обеих темах. Красный — только состояния (ошибка,
  удаление), на цвете мира не строится.

## Typography

- Заголовки и текст — системный гротеск (Segoe UI / system-ui), весовая
  шкала 400–800, display 34px/800 для «Мебель 3D».
- Моноширинный — только для данных: коды образцов (ДСП-08), ID проектов,
  номера записей, размеры. Табличные цифры — через `font-variant-numeric`.
- Заголовки панелей — 13px uppercase muted; подзаголовки групп — 12px
  uppercase amber (иерархия: группа внутри панели).

## Layout

- Редактор — три колонки: слева предметы (268px), центр 3D (flex), справа
  параметры (352px). Панели — `<details>`: Предметы/Параметры/Комната/
  Деталировка раскрыты, «Сдать клиенту»/Видео/ИИ свёрнуты.
- Топбар 56px: бренд, имя проекта, ID-чип, ↶/↷ (SVG), статус сохранения,
  Тема, Библиотека. Тулбар 3D — пилюля по центру низа сцены.
- Брейкпоинты: ≤1100px — колонки уже; ≤900px — правая 290px; ≤720px —
  колонки в одну (предметы, сцена 46vh, параметры), топбар и тулбар
  скроллятся горизонтально, бренд скрыт.

## Elevation & Depth

Одна система теней: `0 10px 28px rgba(0,0,0,.42)` (светлая — тёплая
`0 10px 26px rgba(74,58,28,.16)`), primary-кнопка `0 3px 10px`. Всегда
вынос + мягкое размытие; цветного zero-offset свечения нет (детектор
dark-glow — чисто). Карточки при hover приподнимаются на 2px.

## Shapes

Радиусы 6/8/10px; тулбар и тост — пилюли (999px). Чипы образцов 68px:
цветной блок 24px + имя 10px + код 9px моноширинным. Кнопки минимум
36px высотой (в рядах 32px). Никаких жёстких offset-теней и градиентного
текста.

## Components

- **swatch (образец-чип)** — кнопка с `aria-pressed`, цвет + имя + код;
  `.sel` — янтарная рамка. Используется в параметрах и в экспорте.
- **item-row** — номер 01 (моно), чип цвета фасада, подпись с размерами,
  кнопка ✕; выбранная — янтарная рамка; клавиатура Enter/Space.
- **panel (details)** — hairline-модуль, summary с трейловым ▾; группы
  параметров с подзаголовками; нерелевантные поля скрыты по типу.
- **dialog/toast** — вместо prompt/confirm/alert; тост — пилюля снизу.
- **steps (Сдать клиенту)** — шаги 1–4, инструкция после создания HTML.
- **undo/redo** — SVG-иконки, disabled + счётчик шагов в title; Ctrl+Z/Y
  не работают внутри полей ввода.

## Do's and Don'ts

- Do: показывать каждый цвет чипом с кодом; моноширинным — только данные.
- Do: держать 3D в центре и тёмную тему основной; светлую — бумажной.
- Don't: возвращать «серую админку» без чипов и номеров; не выдумывать
  артикулы поставщика — коды ДСП-xx это подписи системы.
- Don't: трогать формулы `generators/` и сцену ради вида; офлайн без CDN.
- Don't: нативные prompt/confirm/alert и глифы вместо SVG для икон-кнопок.
