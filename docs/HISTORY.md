## 2026-11-07 — фикс пустой экспортной страницы

Жалоба: скачанный HTML открывается, но виден только текст, 3D нет.
Причина (найдена headless Chrome): `three.core.js` не содержит
`WebGLRenderer`/`PMREMGenerator` — они в `three.module.js`.
Экспортёр бандлил только core → `THREE.WebGLRenderer is not a constructor`.

Исправление в `app/exporter.py`:
- Бандим **оба** файла: core → `window.THREE`, module → `Object.assign`
  (только 6 модульных символов: PMREMGenerator, ShaderChunk, ShaderLib,
  UniformsLib, WebGLRenderer, WebGLUtils).
- Каждый файл в своей IIFE, чтобы внутренние имена (`_m1$1`) не
  сталкивались; import module заменён деструктуризацией из `window.THREE`.
- Размер вырос до ~2 МБ, всё ещё <15 МБ.

Проверка headless Chrome:
- До фикса: `Uncaught TypeError: THREE.WebGLRenderer is not a constructor`,
  канваса нет.
- После: ошибок нет, канвас `data-engine="three.js r180"` 749×345 создан.
- `pytest tests -q` → 24 passed, 1 skipped; добавлен регрессионный assert
  на WebGLRenderer в `test_export.py`.
