# Агент 3 — Кровать и стол (Этап 6)

## Что сделано

Созданы два генератора мебели с интерфейсом как у `corpus.js`:
`build(params) → { parts, anim, dims }`, размеры в мм, у каждой детали поле
`cut: [a, b]` для деталировки.

- `app/static/js/generators/bed.js` — кровать: спальное место, изголовье,
  основание (ламели), царги, ножки.
- `app/static/js/generators/table.js` — стол: столешница + 4 ножки (или
  панельные опоры при `supports/opors/legsType === 'panel'`).
- `tests/test_bed_table.mjs` — 37 проверок node-тестами (стиль
  `test_generators.mjs`: `eq`/`close`, русское описание).

**НЕ тронуты** (по заданию): `index.js`, `common.js`, `schema.py` — только
свои файлы + тест. Подключение новых типов в `index.js`, пресеты в
`common.js` и диапазоны в `schema.py` — за основным агентом.

## Интерфейс

```js
import { buildBed } from './bed.js';     // также: export { build } 
import { buildTable } from './table.js'; // также: export { build }
buildBed(params)  // → { parts, anim: {doors:[], drawers:[]}, dims: {w,h,d,lift:0} }
buildTable(params)
```

`parts`: `{ name, kind, cut, size: [x,y,z] мм, pos: [x,y,z] мм, material }`.
`material` только из существующих в `scene.js`: `corpus` / `facade` / `top`.
`kind`: `dsp` (учитывается в площади ДСП `summarizeCut`), `top` (как
столешница в `corpus.js` — в `rows`, но не в площадь ДСП).

Система координат (как в `corpus.js`): `x` — вдоль ширины `0..W`, `y` — от
пола, `z` — `0` в центре, фасадная сторона в `+z`. Для кровати изголовье в
`-z`, изножье в `+z`. Детали не выходят за габариты `dims`.

### Кровать (`bed.js`)

Параметры: `w` — ширина спального места (по умолчанию 1600),
`d` — длина спального места (по умолчанию 2000), `h` — высота изголовья
от пола (по умолчанию 1000), `t` — толщина ДСП 16/18 (по умолчанию 16).
Дополнительно: `plinth`, `lift`, `modules`, `shelves`, `front` и т. п.
игнорируются. `dims: { w, h, d: L, lift: 0 }`.

Детали (14 шт):
| Деталь | cut [a,b] | size [x,y,z] | pos |
|---|---|---|---|
| Изголовье (1) | `[W, H]` | `[W, H, t]` | `[W/2, H/2, -L/2+t/2]`, `facade` |
| Царга (2) | `[L-t, 200]` | `[t, 200, L-t]` | `x = t/2` и `W-t/2`, `y=300`, `z=t/2` |
| Изножье (1) | `[W-2t, 200]` | `[W-2t, 200, t]` | `[W/2, 300, L/2-t/2]` |
| Центральная планка (1) | `[L-t, 200]` | `[t, 200, L-t]` | `[W/2, 300, t/2]` |
| Ламель основания (5) | `[W-2t, 150]` | `[W-2t, t, 150]` | `y=400+t/2`, равномерно по длине |
| Ножка опоры (4) | `[200, 50]` | `[50, 200, 50]` | отступ 60 м
м от торцов, `y=100` |

### Стол (`table.js`)

Параметры: `w` (по умолчанию 1200), `d` (700), `h` — высота (750),
`t` — толщина фартуков/опор (16). `dims: { w, h, d, lift: 0 }`.

Детали (9 шт, режим ножек):
| Деталь | cut | size | pos |
|---|---|---|---|
| Столешница 38 мм (1) | `[W, D]` | `[W, 38, D]` | `[W/2, H-19, 0]`, `kind: top`, `material: top` |
| Ножка стола (4) | `[H-38, 50]` | `[50, H-38, 50]` | отступ 100 от краёв (кламп для узких) |
| Царга стола (4) | `[len, 120]` | продольные `[run,120,t]`, поперечные `[t,120,run]` | `y = H-38-60` |

Режим панелей (`supports/opors/legsType === 'panel'`, 4 детали): 2 панели
`t × (H-38) × (D-100)` вместо ножек + задний фартук между ними.

## Допущения (нет правил цеха)

- Кровать: ножки 200 мм, высота царг 200 мм, ламелей 5 шт глубиной 150 мм,
  сечение ножек 50×50, отступ ножек 60 мм. Central plank всегда добавляется
  (для опоры ламелей на широких моделях).
- Стол: столешница без свеса (размер — как задал оператор), отступ ножек
  100 мм, фартуки 120 мм. Панели-опоры: глубина `D-100`.
- Мусорные числа (`0`, `NaN`, `null`, строки) заменяются дефолтами,
  `NaN` в детали не попадает (проверено тестом).
