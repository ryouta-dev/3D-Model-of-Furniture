## Что сделано

1. **Запись канваса в WebM** — новый файл `app/static/js/video.js`:
   - берёт канвас сцены через `getCanvas()` из `scene.js`,
   - делает `canvas.captureStream(30)` (фолбэк без аргумента),
   - пишет `new MediaRecorder(stream, ...)` с авто-подбором mime-типа: `vp9,opus` → `vp8,opus` → `video/webm` → дефолт,
   - битрейт 8 Мбит/с, чанки по 500 мс, по окончании — скачивание файла `<id-проекта>-video.webm`,
   - облет включает через существующий режим презентации `setPresent(true)` + `fitView()` (6 сек движение + 2 сек пауза на цикл, переиспользован как есть),
   - длительность выбирается в UI: 8 / 16 / 24 сек (по умолчанию 8 — полуоборот), авто-стоп по таймеру, есть ручной «Стоп»,
   - статус-строка с обратным отсчётом, защита от пустого проекта, от отсутствия MediaRecorder и от пустого blob.
   - `README`-логика: автостоп презентации при клике по модели уже есть в `scene.js` — в подсказке указано не трогать модель во время записи, чтобы облет не остановился посреди видео.

2. **`app/static/js/scene.js` — только видео-экспорты** (по владению):
   - в объект, возвращаемый `createScene`, добавлен `canvas: renderer.domElement`,
   - внизу добавлен экспорт `getCanvas()`.
   - Формулы, генераторы и остальная сцена не трогались.

3. **`app/static/index.html` — кнопки и панель**:
   - в тулбаре `#view-toolbar` добавлена кнопка `#btn-video` «▶ Запись видео»,
   - добавлена панель `#video-panel` «Видео и публикация»: выбор длительности, кнопки записи/стопа, статус `#video-status` и инструкции,
   - добавлен тег `<script type="module" src="/js/video.js">` (страница и так грузит только `main.js`, поэтому отдельная загрузка — без правок `main.js`).

4. **Публикация — только инструкции в UI** (как требовалось, API позже, ключей нет):

   - прямо указано: автоматическая публикация по API — в следующей версии, ключи хостинга в UI не вводятся.

`generators/` и `app/ai.py` не тронуты.

## Ограничения

- Видео пишется в размере текущего окна 3D (больше окно → выше качество). Фиксированное 1280×720 не ставили, чтобы не ломать layout редактора; подсказка про «не трогайте модель» важна, так как клик останавливает презентацию.
- Размерные метки — HTML-оверлей, в видео не попадают (в канвас не входят). Это плюс: видео чище.
- WebM, не MP4. Конвертация через ffmpeg (ТЗ п.7.3) не делалась — бэклог на доработку.
- Публикация по API не реализована by design (ТЗ п.8: первая версия — ручная инструкция).
